## 🌟 Project Overview

**Velvet Brew Café** is a **modern, ultra-premium coffee Website** crafted to provide users with an immersive online café experience.  

- **Premium aesthetic**: Clean, elegant, and sophisticated UI.  
- **Interactive sections**: Hero, Menu, About, Testimonials, Parallax effect, Contact.  
- **Fully responsive**: Works seamlessly on mobile, tablet, and desktop.  
- **Modern tech stack**: HTML5, CSS3, Bootstrap 5, JS for smooth interactions.  

---

## 🎨 Features

- **Hero Section**: Elegant overlay with call-to-action buttons.  
- **Menu Showcase**: Beautiful coffee cards with images, descriptions, and order buttons.  
- **Parallax Section**: Scroll effect showcasing premium vibes.  
- **About Section**: Stylish layout highlighting café story, stats, and experience badge.  
- **Testimonials**: Cards with user images, reviews, and modern shapes.  
- **Contact Form**: Fully functional with floating labels and icons.  
- **Footer**: Decorative shapes, social links, newsletter input.
